# Open Grok Bot

An open source take on Grokbot: an AI bot you can tag in social threads to answer questions, explain context, and fact-check posts.

> Status: early setup. Nothing works yet.

## Goals

- Answer when mentioned in a thread, using the full thread as context
- Pluggable LLM providers
- Self-hostable, with a simple config
- Transparent: open prompts, open code

## Project structure

```
open-grok-bot/
├── src/        # bot source code
├── tests/      # tests
├── docs/       # design notes and decisions
└── README.md
```
